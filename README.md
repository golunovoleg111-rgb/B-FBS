# B-FBS

Коммерческая складская система для FBS: единая база сотрудников и остатков, конструктор склада, зоны и коробки, QR-коды, импорт номенклатуры Wildberries, пополнение, перемещения, ревизии и задания сборщика.

## Быстрый запуск

Требуется Node.js 22.5 или новее.

```powershell
corepack enable
pnpm install --frozen-lockfile
$env:BFBS_ADMIN_PASSWORD='Замените-на-надежный-пароль'
pnpm start
```

Откройте `http://localhost:8080`. Первый логин — `Admin1`, пароль берется из `BFBS_ADMIN_PASSWORD`. Если переменная не задана при первом запуске, используется `Admin123`; после входа смените пароль в разделе «Личный кабинет».

Для телефонов и компьютеров в одной сети откройте `http://IP-КОМПЬЮТЕРА:8080`. Разрешите входящие подключения к порту 8080 в брандмауэре Windows.

## Режимы работы

- Онлайн/LAN: все 3–4 рабочих устройства используют один адрес сервера и общую SQLite-базу. Обновления опрашиваются каждые 2,5 секунды, конфликтующие изменения объединяются по журналу операций.
- Автономно: интерфейс и последнее состояние сохраняются на устройстве. При восстановлении связи отложенные изменения синхронизируются.
- GitHub Pages: автономная демонстрация без общей серверной базы. Для рабочих сотрудников используйте Node.js-сервер или Docker.

## Импорт WB Seller

В разделе «Учет склада» нажмите «Импорт WB». Поддерживаются CSV, TSV, XLSX и XLS. Excel-файлы разбираются локально в браузере, поэтому импорт работает и в автономном режиме без сервера. Из файла используются только колонки «Артикул», «Баркод» и «Размер»; названия `vendorCode`, `sku/ШК`, `techSize/wbSize` также распознаются.

## Роли

- Администратор: все разделы, сотрудники и экспорт резервной копии.
- Менеджер: склад, номенклатура, перемещения, ревизии и задания.
- Сборщик: остатки, схема, перемещения и сборочные задания.
- Ревизор: схема, остатки и ревизии.

## Данные и резервная копия

База находится в `data/b-fbs.sqlite`. SQLite работает в WAL-режиме. Полную JSON-копию можно скачать в разделе «Личный кабинет». Для переноса сервера остановите приложение и скопируйте всю папку `data`.

Переменные окружения:

- `PORT` — порт, по умолчанию `8080`.
- `BFBS_DATA_DIR` — папка базы, по умолчанию `./data`.
- `BFBS_ADMIN_PASSWORD` — пароль первого администратора при создании новой базы.
- `BFBS_SESSION_HOURS` — срок сессии, по умолчанию 24 часа.
- `WB_API_TOKEN` — серверный ключ WB для будущего прямого API-подключения; никогда не размещайте его во frontend.
