# API Integration Plan

Кнопка API Интеграция добавлена в PR#4 как точка входа.

Будущая логика:
1. Администратор подключает ключ API Wildberries.
2. Раздел Заказы показывает актуальные заказы WB.
3. Заказы, переведенные менеджером на сборку, становятся Готовыми заданиями.
4. Отгруженные и закрытые задания попадают в Завершенные.

На PR#4 внешние API-запросы и ключи не используются.
