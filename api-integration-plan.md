# Интеграция WB API

Реализовано:

1. Токен WB категории «Маркетплейс» хранится только в окружении Node.js-сервера.
2. Сервер получает новые FBS-заказы через официальный `GET /api/v3/orders/new`, ограничивает частоту запросов кэшем и возвращает понятные ошибки авторизации/лимитов.
3. Раздел «Заказы и сборка» сопоставляет заказы с номенклатурой по ШК и с фактическими остатками коробок.
4. Менеджер выбирает часть заказов или все доступные и формирует многопозиционный RoadMap.
5. Scanner Mode ведёт сборщика по позициям и коробкам, списывая остаток только после корректной пары QR коробки + ШК товара.

Следующий безопасный этап после проверки на реальном кабинете WB: создание поставки, добавление выбранных заказов в поставку и печать официальных WB-стикеров. Эти операции меняют статус заказов в WB и поэтому должны запускаться отдельным подтверждённым действием менеджера.
